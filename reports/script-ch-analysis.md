# ch 스크립트 동작 분석

검사 범위: `frontend/script.js`, `frontend/ch/index.html`, `backend/index.js`.

백엔드 Lambda 코드 있음: `backend/index.js`. `serverless-http`로 Express 앱을 Lambda handler로 내보낸다 (`backend/index.js:1`, `backend/index.js:936-937`).

| 항목 | 현재 동작(파일:행) | 문제 여부 | 수정 제안 |
| --- | --- | --- | --- |
| 시 생성 API 언어 값 | ch 페이지의 select 값은 `ch`다 (`frontend/ch/index.html:172-176`). 제출 시 이 값을 그대로 `{ topic, language, form }`에 넣어 `/generate-poem`으로 보낸다 (`frontend/script.js:1245-1247`, `frontend/script.js:1266-1278`). API 요청용 `ch`→`de-CH` 또는 `Swiss German` 변환은 없다. `languageMap.ch.ttsLang`의 `de-CH`는 TTS 전용이다 (`frontend/script.js:17-49`, `frontend/script.js:33`). | 현재 백엔드 계약과 일치. | API 언어 코드 `ch`와 BCP 47 TTS 코드 `de-CH`의 용도를 문서화. API 계약을 BCP 47로 바꿀 때 프런트·백엔드 동시 변경. |
| Lambda 프롬프트의 ch 처리 | Lambda는 `ch`를 지원 언어로 허용하고 (`backend/index.js:54-89`), `languagePromptMap.ch`를 `auf Schweizerdeutsch`로 정한다 (`backend/index.js:70`). 생성 프롬프트 끝에 이 값이 들어간다 (`backend/index.js:867`, `backend/index.js:880-893`). 결과: `Please write a poem about {topic} auf Schweizerdeutsch.` 또는 형식 지시 뒤 같은 문장. | 문제 없음. `ch`가 독일어 일반값으로 바뀌지 않음. | Swiss German 출력 품질이 중요하면 예시 어휘·철자 규칙을 프롬프트에 추가. |
| TTS 언어와 음성 선택 | `SpeechSynthesisUtterance.lang`는 ch에서 `de-CH`다 (`frontend/script.js:33`, `frontend/script.js:1068-1071`). 음성은 정확히 `de-CH`를 먼저 찾고, 없으면 첫 `de-*` 음성을 고른다 (`frontend/script.js:896-902`). 따라서 `de-DE`도 후보지만, 브라우저 voice 목록 순서에 따라 `de-AT` 등도 먼저 선택될 수 있다. `de-*`도 없으면 1.2초 대기 뒤 unsupported 상태가 된다 (`frontend/script.js:904-920`, `frontend/script.js:1038-1043`, `frontend/script.js:1163-1167`). | Swiss German 음성이 없을 때 대체 언어가 고정되지 않음. `de-DE` 보장 없음. | `de-CH` 다음 `de-DE`를 명시적으로 찾고, 그다음 다른 `de-*`를 찾도록 우선순위 설정. 대체 중임을 UI에 표시. |
| 서버 TTS의 ch 처리 | 서버 TTS 대상은 `ko`, `en`, `ja`뿐이다 (`frontend/script.js:714`, `frontend/script.js:869-870`, `frontend/script.js:935-936`; `backend/index.js:42-49`, `backend/index.js:668-672`). ch는 `/synthesize-speech` 요청을 만들지 않고 브라우저 TTS만 쓴다. | 기능 제한. ch의 "AI voice"는 서버 음성이 아님. | ch 서버 TTS 제공 전까지 UI에 기기 음성임을 명시. 서버 TTS를 추가하면 `ch` 음성·발음 검증과 토큰 허용 목록을 함께 추가. |
| UI 번역 사전과 정적 라벨 | ch 전용 사전 있음: 처리·오류·필수입력 메시지 (`frontend/script.js:68`, `frontend/script.js:104`, `frontend/script.js:139`), 시 형식 옵션·라벨 (`frontend/script.js:674`, `frontend/script.js:697`), TTS 문구 (`frontend/script.js:743`), 쿠키 문구 (`frontend/script.js:511-525`). 범용 `data-i18n-*` 번역기는 없고, `data-i18n-form-label` 한 항목을 직접 갱신한다 (`frontend/script.js:1195-1208`). | 정상 실행 중 영어 폴백 없음. 사전에서 ch를 찾음. | 정적 HTML과 JavaScript 사전을 같은 검증 대상으로 유지. |
| ch 정적 영어 라벨 덮어쓰기 | 정적 HTML에는 `Poem form`, `Speed`, `AI voice`, stop `aria-label="Stop"`가 있다 (`frontend/ch/index.html:218`, `frontend/ch/index.html:235-242`). defer된 `script.js`는 문서 lang `de-CH`를 `ch`로 바꾼 뒤 (`frontend/script.js:704-708`), form label을 `Gedichtform`으로, TTS label을 `Stopp`, `Tempo`, `KI-Stimm`으로 덮어쓴다 (`frontend/script.js:1195-1208`, `frontend/script.js:854-870`). | JavaScript가 실행되면 문제 없음. JavaScript 실패·비활성 시 영어가 남음. | 정적 ch HTML도 Swiss German 라벨로 교체. JavaScript는 보조 갱신만 유지. |
| 쿠키 동의 방식과 재설정 | 자체 DOM 배너·모달. 상태는 `localStorage.aiAndPoemCookieConsent`에 JSON으로 저장한다 (`frontend/script.js:1324-1347`, `frontend/script.js:1469-1565`). Google Consent Mode v2 `gtag('consent', 'update', ...)`를 호출한다 (`frontend/script.js:1336-1346`). `__tcfapi`, TCF 문자열, 외부 CMP SDK 호출은 `frontend/`에서 찾지 못했다. footer에 "쿠키 설정" 버튼을 동적으로 추가해 동의 변경·철회를 연다 (`frontend/script.js:1576-1597`). 초기 HTML도 저장값을 읽어 gtag 기본 동의를 정한다 (`frontend/ch/index.html:124-137`). | Google 인증 CMP·IAB TCF 구현 아님. EEA 개인화 광고에 TCF가 필요한지는 Google 광고 설정·법률 검토 필요. | TCF가 요구되는 배포라면 인증 CMP를 도입하고, 자체 localStorage 상태와 CMP 동의 신호의 단일 기준을 정함. |
| 주제·시 저장과 로그 | 프런트는 주제·시를 요청·DOM·TTS controller 메모리에만 둔다 (`frontend/script.js:1245-1278`, `frontend/script.js:1283-1288`, `frontend/script.js:876-890`). localStorage에는 동의와 TTS 속도만 저장한다 (`frontend/script.js:711`, `frontend/script.js:765-771`, `frontend/script.js:1328-1347`). analytics 동의 뒤 TTS 이벤트는 언어·재생원·속도만 gtag로 보낸다 (`frontend/script.js:774-781`, `frontend/script.js:1007`, `frontend/script.js:1017`, `frontend/script.js:1055`). Lambda는 주제를 OpenAI 생성 프롬프트로 전송하고 (`backend/index.js:839-882`, `backend/index.js:891-902`) 시를 응답으로만 돌려준다 (`backend/index.js:806-813`, `backend/index.js:913-915`). DynamoDB에는 TTS 일회용 nonce `jti`, `expiresAt`만 저장하며 주제·시 원문은 저장하지 않는다 (`backend/index.js:741-759`). ch는 서버 TTS 비대상이라 이 nonce도 만들지 않는다. | 영구 저장 코드는 없음. 단, 주제·시는 OpenAI API로 전송됨. OpenAI 실패 시 provider `errorPayload`를 서버 로그에 남긴다 (`backend/index.js:924-928`); 원문 반사 여부는 provider 응답에 좌우됨. | 개인정보 고지에 OpenAI 전송을 명시. 오류 로그에서 provider 응답을 allowlist·마스킹해 입력 반사 위험을 줄임. |
