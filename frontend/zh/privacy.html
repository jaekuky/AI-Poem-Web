隐私政策

生效日期：2026年10月5日

AI & Poem（以下简称“本服务”）是 Ryu Jae-kuk（以下简称“我们”）在 https://ai-and-poem.art 提供的 AI 诗歌生成工具。本政策说明我们处理哪些信息、为什么处理、由谁接收、保存多久，以及您有哪些选择。

本政策以韩语和英语发布。其他语言版本均为译文。如韩文版本与英文版本不一致，以韩文版本为准；如译文与英文版本不一致，以英文版本为准。

1. 我们处理的信息

  • 当您请求生成诗歌时，我们会收到您输入的主题（最多 200 个字符）以及您选择的语言和诗歌形式。
  • 当您在韩语、英语或日语页面按下朗读按钮时，我们会收到生成的诗歌正文及其语言，用于制作 AI 语音。在其他语言页面，或 AI 语音不可用时，由您设备内置的语音朗读诗歌。部分浏览器使用在线语音，会把文本发送给浏览器或操作系统的提供商。
  • 当您发送电子邮件联系我们时，我们会收到您的邮箱地址和留言内容。
  • 页面加载时，Cloudflare（我们的网站托管商）会处理您的 IP 地址、浏览器信息和请求时间。分析或广告脚本运行时，Google 也会处理类似信息。我们的后端服务器只保存错误代码、处理时间、请求 ID 等运行日志，不记录您的 IP 地址、主题或诗歌正文。
  • 您的浏览器在本地存储中保存两个条目：aiAndPoemCookieConsent 保存您的同意选择，aiAndPoemTtsSpeed 保存朗读速度。Google Analytics 和 Google AdSense 可能根据您的同意设置 Cookie。

我们不收集姓名或电话号码。本服务没有用户账户。

2. 使用目的

  • 生成您请求的诗歌和朗读，并防止同一朗读请求被使用两次。
  • 回复您的咨询。
  • 保障本服务安全、防止滥用并修复错误。
  • 仅在您允许分析 Cookie 时，使用 Google Analytics 统计访问情况。
  • 通过 Google AdSense 展示广告。仅在您允许广告 Cookie 时展示个性化广告。

如果您位于欧洲经济区（EEA）、英国或瑞士，我们处理信息的法律依据是提供您请求的服务（诗歌、朗读和回复）、您对分析和广告 Cookie 的同意，以及我们在安全和稳定运行方面的正当利益。

3. 服务提供商

我们不出售或出租个人信息。以下服务提供商为运行本服务处理数据。

  • OpenAI OpCo, LLC（美国）根据您的主题生成诗歌，并根据诗歌正文制作 AI 语音。根据其 API 数据政策，OpenAI 为监测滥用最多保存输入和输出 30 天，且不将其用于训练模型。联系方式：privacy@openai.com。
  • Amazon Web Services 在大韩民国首尔区域运行我们的后端，包括 AWS Lambda 服务器、Amazon CloudWatch 运行日志，以及记录一次性朗读令牌的 Amazon DynamoDB。
  • Cloudflare, Inc.（美国）托管本网站，并通过其全球网络分发。联系方式：privacyquestions@cloudflare.com。
  • Google LLC（美国）提供 Google Analytics 4（衡量 ID G-1CVHJYZWNC）、Google AdSense（发布商 ID ca-pub-7349192768683799）以及接收咨询的 Gmail 邮箱。您可以通过 Google 的隐私权联系表单与其联系。

4. 跨境传输

部分信息会传输到大韩民国境外。每次您使用相关功能时，传输均通过加密连接（HTTPS）进行。

  • 位于美国的 OpenAI 在您请求诗歌时收到主题、语言和诗歌形式，在您请求 AI 朗读时收到诗歌正文，并为监测滥用最多保存 30 天。
  • 位于美国的 Cloudflare 通过其全球网络在页面加载时收到连接信息，并按照其自身的保留政策保存。
  • 位于美国的 Google 收到用于分析和广告的连接信息及 Cookie 信息，并保存咨询邮件。保存期限见第 7 条。

后端信息在 AWS 首尔区域处理。对于欧洲经济区、英国和瑞士的用户，欧盟和英国已认定大韩民国提供充分的数据保护水平。向美国服务商的传输以这些服务商提供的保障措施为依据，例如标准合同条款或欧盟-美国数据隐私框架。

您可以通过不使用诗歌生成和 AI 朗读来拒绝向 OpenAI 传输，但此时这两项功能无法使用。您可以在 Cookie 设置中拒绝分析和广告 Cookie，拒绝后网站其他功能仍可正常使用。连接信息是传送网站本身所必需的。

5. 广告

第三方供应商（包括 Google）会使用 Cookie，根据用户以前对本网站或其他网站的访问情况投放广告。Google 通过使用广告 Cookie，可以根据用户对本网站和/或互联网上其他网站的访问情况，让 Google 及其合作伙伴向我们的用户投放广告。详情请参阅Google 如何在广告中使用 Cookie。

您可以在 Google 广告设置中停用个性化广告。您也可以在 aboutads.info 上停用部分第三方供应商为个性化广告使用 Cookie。如需了解 Google 如何使用来自使用其服务的网站的信息，请参阅Google 关于合作伙伴网站的政策。

如果您不允许广告 Cookie，您看到的广告不会个性化。

6. Cookie 与同意

首次访问时，横幅会询问您是否允许分析和广告 Cookie。在您允许之前，两者都保持关闭。必要条目只保存您的选择。

您可以随时通过每个页面底部的“Cookie 设置”按钮更改或撤回同意。撤回后，我们不再使用分析和广告 Cookie。已保存在您设备上的 Cookie，可以在浏览器设置中删除。

我们使用 Google 同意模式（Consent Mode）。即使您拒绝分析 Cookie，Google Analytics 仍可能收到不使用 Cookie 的统计信息。如果您位于欧洲经济区、英国或瑞士，Google 的同意消息还会另行询问您的广告选择，Google AdSense 会遵循您在其中作出的选择。

7. 保存期限与删除

  • 主题、诗歌正文和朗读音频不保存在我们的服务器上，发送响应后即予丢弃。朗读音频仅在页面打开期间保留在浏览器内存中。
  • OpenAI 最多保存 API 输入和输出 30 天。
  • 一次性朗读令牌的记录只包含随机 ID 和过期时间。令牌在 10 分钟后过期，之后记录会被自动删除。
  • 后端运行日志在 30 天后删除。
  • 咨询邮件在回复之日起 1 年后删除。
  • Google Analytics 最多保存与标识符关联的事件数据 14 个月。
  • Cloudflare 按照其自身的保留政策保存连接日志。
  • 浏览器中存储的信息会保留在您的设备上，直到您将其删除。

保存期限届满后，我们通过自动过期或手动删除，以无法恢复的方式永久删除电子记录。我们不保留纸质记录。

8. 您的权利

  • 您可以通过电子邮件要求查阅、更正、删除个人信息，停止处理，或获取副本。由于我们不保存主题和诗歌，可能没有与您相关的信息。
  • 您可以随时通过“Cookie 设置”按钮撤回对 Cookie 的同意。
  • 如果您位于欧洲经济区、英国或瑞士，也可以向当地数据保护监管机构投诉。

我们会在适用法律规定的期限内答复。

9. 儿童

本服务不面向未满 14 周岁的儿童。在规定了更高网络服务同意年龄的国家（部分欧盟国家最高为 16 岁），低于该年龄的用户需要获得父母或监护人的许可。如果您认为儿童向我们提供了个人信息，请与我们联系，我们会及时删除。

10. 安全措施

所有连接均使用 HTTPS 加密。只有运营者可以访问服务器设置和 API 密钥，我们只保存本服务所需的信息。但没有任何互联网传输或存储方式是绝对安全的。

11. 政策变更

修改本政策时，我们会在此页面发布新版本并注明新的生效日期。重要变更也可能在网站上另行通知。

12. 联系我们
